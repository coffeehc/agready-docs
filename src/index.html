START WITH A REAL TASK

Make the first
workflow count.

Before running an agent, define what a useful result looks like. Start small, with inputs you can inspect and an outcome you can verify.

This is a preparation checklist. Continue with the illustrated setup and first-task guide for self-hosted resources. Public hosted signup is not offered here.

  1. 01

    Choose a bounded task.

    Specify the input, expected output and what is out of scope.

  2. 02

    Check your release and setup.

    Confirm model access, available tools and the permissions your environment requires.

  3. 03

    Review the result.

    Check sources, artifacts and side effects before relying on the outcome.
