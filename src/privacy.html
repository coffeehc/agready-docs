WEBSITE INFORMATION

Website Privacy Notice

How this website handles visits, browser preferences and contact messages.

Last updated: October 26, 2026

Scope

This notice describes the public AgReady.ai website, including its documentation and blog. These are static content pages, not an account registration or agent-task submission service.

This notice does not cover every AgReady installation. Data handling in an installation depends on its deployment, permissions, connected tools and model providers. Reading this website does not submit an agent task to those providers.

Website delivery and performance measurement

Cloudflare hosts and delivers this website. Requests to the website are handled by Cloudflare, and the website includes a Cloudflare Insights performance beacon. This is separate from the optional Google Analytics integration described below.

For information about Cloudflare's handling of performance measurements, see its RUM beacon documentation and privacy policy.

Google Analytics preference

Google Analytics is not currently configured on this website. The site's Google Analytics integration therefore does not load its Google Analytics script.

When a valid Google Analytics configuration is present and this browser has no saved choice, a non-blocking banner offers equally accessible Allow and Decline buttons. No Google Analytics script loads before an affirmative choice. With Google Analytics unconfigured, no automatic banner appears. You can reopen the preference panel from the footer to change or withdraw your choice. If browser storage is unavailable, the choice applies only to the current page and you may be asked again on another visit. The preference controls only this integration: it does not switch off Cloudflare's performance beacon or website delivery.

Browser storage

When you choose a Google Analytics preference, the website saves it in this browser's local storage under agready.analytics-choice.v1. The site does not set an expiry for this preference. You can change it using the footer's Google Analytics preference panel or remove it by clearing this site's browser data. Your browser may also remove stored data.

Changing or clearing the preference does not delete information already sent to a provider.

Email and public contact

If you email hello@agready.ai, your message includes your sender address and any content or attachments you provide. These are used to read and respond to your inquiry. Messages are forwarded through Cloudflare Email Routing to a Google-hosted mailbox.

Please do not send passwords, API keys or sensitive task data. Project profile: coffeehc. Visiting that profile takes you to GitHub, which has its own privacy practices.

External links

Links to release resources, source code and other services may take you to services with their own privacy practices. Review the relevant service's information before providing data or using it.

Questions

For questions about information handled through this website or an email you have sent, contact hello@agready.ai. Do not include credentials or private instance details in your message.

Google Analytics preference

Google Analytics is not configured. No Google Analytics script is loaded.

Cloudflare provides website delivery and performance measurement separately. This preference controls only optional Google Analytics; it does not disable Cloudflare measurement.

If Google Analytics is configured and you allow it, this site measures page visits and selected navigation clicks. Its integration omits URL query parameters and does not intentionally send task content, file contents or email addresses. These limits describe this integration, not every service used to deliver the website.

Your choice is saved in this browser. Declining Google Analytics does not affect page access. You can change this preference here or clear this site's browser data.
