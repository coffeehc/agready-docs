Already have a working instance? Start with the outcome you need, then follow the relevant guides below. These are suggested reading paths, not measured customer results or a promise that every installation has the required tools.

Prepare a research brief from documents or source pages

  1. Start a session with the question, source scope, required freshness and output format.
  2. Provide the documents, or check the tools and authorized source access before asking for web research. Reading a URL, searching and interacting with a website are different operations.
  3. Ask for a brief that links important conclusions to evidence and keeps missing or conflicting information visible.

Working from public discussions? Follow the source-backed user-needs research tutorial for a reusable brief and evidence checks.

Check the result: open the cited sources, verify that they support the conclusions and distinguish retrieved evidence from the agent’s interpretation. A polished answer alone does not establish that research happened.

Revise an existing report or produce a saved document

  1. Attach the source and specify a separate output, including the audience, required sections and file format. Confirm that the necessary file tools are available.
  2. Keep revisions in the assignment’s session and state which earlier requirements a correction replaces.
  3. Separate drafting from sending or publishing. Producing a document is not permission to distribute it.

Combining several PDFs? Use the document comparison and spreadsheet tutorial to check extraction before requesting a saved file.

Check the result: open the actual saved file, compare names, figures and meaning with the source, and confirm that the original remains intact when requested. A filename in a response is not proof that a file was delivered.

Repeat a useful review without losing control

  1. Complete and review the underlying task first. Use a Skill for its reusable method and memory for relevant lasting context; neither grants additional access.
  2. Configure a recurring trigger with bounded instructions, an appropriate fire limit and a checked next-run time.
  3. Inspect the target session’s output after activation. Use human oversight for external actions and operations guidance for service availability.

Check the result: a fired trigger records activation, not a verified completed task. Stop future activations when the task’s inputs or permission boundaries are no longer appropriate.

When an assignment genuinely needs separate specialists, read Agent teams. Start with one session when coordination would add no value.
