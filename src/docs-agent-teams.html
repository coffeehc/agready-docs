Work with an AI agent team in AgReady

An agent team brings a manager and specialist agents together around a goal. Use this guide to create a team, inspect collaboration and keep its work within the limits you set.

Reviewed October 28, 2026

This guide describes the current development interface; labels and availability may differ in other versions. The creation form was checked without creating a team. Team execution, archive and restore behavior were reviewed from product documentation and implementation, not exercised in this check.

When to use an agent team

An agent team is useful when a goal involves several specialties and someone needs to coordinate the work. In AgReady, you work with a team manager, who can recruit specialist agents, assign work, review their reports, and bring the results together.

Start with a normal session for a straightforward task. Use a team when coordination adds value—not simply to increase the number of agents.

Create the team

  1. Select New team in the session sidebar.
  2. Enter a Team name.
  3. Describe its ongoing Team responsibilities.
  4. Select Create agent team and wait for initialization.
  5. Open View manager session when the team is ready.

Responsibilities describe what the team is for. They are not a substitute for a specific first task or permission to take every possible business action.

Give the manager a bounded first goal

Describe the outcome, available materials, allowed actions, and how you will judge the result. For example:

Review these product documentation pages and identify the three most important gaps for a first-time user. Use only the supplied pages. Return evidence links and suggested outlines. Do not publish changes, contact anyone, or create recurring tasks.

This is an instruction example, not a claim that the task has been tested successfully.

The manager may propose a first pilot or ask for a missing decision. Specialist agents are recruited as needed; creating a team does not require filling every possible role in advance.

Inspect progress and results

Open the team information panel to see its organization status, manager, active member count, and goals. Team chat shows collaboration records, including assignments, reports, and deliveries.

  • Ready describes the team’s organization, not a completed goal.
  • A member report is material for the manager to review.
  • Delivered by manager records the manager’s delivery; inspect the actual result before accepting it as correct.

Teams use the models, tools, Skills, and workspace access available to their sessions. A role description does not grant additional access. If an action requires your approval, review that original request rather than treating the team’s goal as blanket permission.

Change direction or stop work

Tell the manager clearly when you want to revise, pause, resume, or cancel a specific goal. Check the resulting goal status and the manager’s explanation. A user-requested pause should remain in effect until you authorize resuming.

To stop the team as an organization while preserving its records, use Archive team. Restore team is available for an archived team. Stopping an individual session run is not the same as archiving the entire team.

If something goes wrong

If creation reports an error, use Retry creation with the original details instead of repeatedly creating new teams. If work is blocked, ask the manager for the affected goal, evidence collected, attempted approaches, and the exact decision or access required.

Assess the team by useful, verified deliverables—not by how many members it created or how much conversation it produced.
