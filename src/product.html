PRODUCT

A workspace for work that takes more than one step.

AgReady brings task context, tools and reusable instructions into a session, so an assignment can be worked on and reviewed as a whole.

Development preview

These pages describe the current product direction and development concepts, not a promise that every capability is available in a released package. The Get started guide covers self-hosted resources and setup concepts; available versions are listed in the release catalog.

Built on the xAgent foundation

AgReady grew out of a branch of xAgent and builds on that foundation, with its own product direction.

Start with a bounded assignment

A useful task has an outcome, a source of truth and clear limits. Instead of “research this topic,” specify the material to use, the deliverable to produce and the actions that require your approval.

For example: compare two supplied project notes, identify disagreements, and draft a decision brief with source references. That is an illustrative task, not a claim about measured product performance.

Keep the parts of the work together

  • Sessions provide the context for a task and its conversation.
  • Tools make external actions possible where configured and permitted.
  • Skills provide reusable instructions for recurring kinds of work.
  • Memory can contribute context beyond the immediate exchange; it should not replace original evidence.
  • Workspace files hold the material you intend the agent to work with.

Available integrations and behavior depend on the configuration and version. See core concepts for the boundaries between these parts.

Review outcomes, not just activity

A tool returning successfully does not prove that an assignment is complete. Inspect the deliverable, check its sources, and confirm that the requested limits were respected. For actions that affect other people or systems, decide the approval boundary before starting.

Our task briefing guide gives you a reusable way to define those checks.

Prepare your first assignment

Choose non-sensitive sample material and a result you can check yourself. Start with reading and drafting before adding actions that affect other people or systems.

The documentation introduces the concepts; the FAQ covers access, data handling and release status.
