Release & access

A note on the name

The public binary distribution currently linked here is named xAgent. AgReady is the current product direction; do not assume every development-branch capability is included in this release.

The official public release repository provides binaries, checksums and licensing documents. Downloading a binary does not mean the product is free to use or open source. Read the supplied LICENSE and EULA before use; this guide does not interpret or extend those terms.

These links open existing official release resources. This preview does not provide an AgReady account signup, free trial, license purchase or hosted workspace. A separate commercial access route has not been published on this site.

Before installation

  • Match your platform. The referenced release lists Linux and macOS, each in AMD64 and ARM64 variants. Do not use this guide as a claim of Windows support.
  • Prepare model access. You need an appropriate model endpoint and credentials for your chosen setup. Keep credentials out of public tickets, screenshots and workspace material.
  • Decide what the agent may access. Start with non-sensitive sample files and limited permissions. Do not connect production accounts for the first test.
  • Back up before upgrading. Preserve configuration, database, workspaces and relevant plugin state. Check the release-specific upgrade notes.

Install & verify

  1. Open the official installation instructions and review the supported environment and installer behavior before running anything.
  2. For manual installation, choose the archive matching your operating system and CPU architecture from the v0.1.1 release assets. The asset names distinguish linux, darwin, amd64 and arm64.
  3. Verify the downloaded archive against its matching entry in SHA256SUMS. The official checksum instructions explain how to check one archive or the full set.
  4. Follow the release documentation for startup and first-time setup. Configure the model and confirm its connection test succeeds before attempting the first task.
Successful download is not successful setup.

Check that the expected version starts, you can access your own instance, model connectivity works, and the workspace contains only the files intended for the test.

Your first task

Use two short, non-sensitive notes with a few facts that you can verify yourself. Ask for a small, reviewable output rather than a broad autonomous assignment.

EXAMPLE TASK

Read the two notes I provided. Write a short brief containing the main findings, the source note for each finding, and any unresolved questions. Do not browse the web, install software, send messages, or change the source files. Ask before any action outside this scope.

Success criteria: each finding is supported by a supplied note; unsupported points are labelled as uncertain; the output follows the requested structure; no unapproved action occurred. If the result is wrong or incomplete, narrow the task and inspect the available execution details before trying again.

Version boundaries

  • This page references the publicly listed Server 0.1.1 release, not the separate 0.0.13 commercial version.
  • Server, desktop client, plugins and runtime assets may have independent versions. A server update does not imply that every component was updated.
  • A successful tool call does not prove that the task's objective was achieved. Review the actual result.
  • This website is an early preview. The commercial acquisition path and production privacy policy still need to be finalized before a full public launch.
