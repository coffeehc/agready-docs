Frequently asked questions

Clear answers about this preview, the product concepts and the choices that remain yours.

How is AgReady related to xAgent?

AgReady grew out of a branch of xAgent and builds on that foundation. It has its own product direction; this relationship does not mean the two products share the same releases or setup instructions.

Can I install or sign up for AgReady here?

Self-hosted resources are available through the Get started guide. Check the official release catalog for the version and platform you need. This website does not provide a public hosted login or self-service signup; ask the administrator for access to an existing instance.

Are all described capabilities available now?

These pages describe the current development direction. Feature availability depends on the version and deployment.

Is AgReady just a chat interface?

The product direction is a workspace for multi-step assignments, combining session context with tools, skills, memory and working files. Whether a specific assignment can be completed depends on the available model, tools, access and task boundaries.

Does it act without asking?

Do not assume every action will have the same approval behavior. State your limits and configure permissions before use. Actions such as sending a message, publishing a file or changing a production system should have an explicit authorization boundary.

Does my data stay on my machine?

Not necessarily. Model requests and tools can involve external services. The deployment, providers, integrations and their settings determine the data flow. Review those details before supplying sensitive material.

Is it free or open source?

Pricing and license details will need to accompany the confirmed AgReady distribution. This preview does not offer a free-use or open-source license.

What should my first task be?

Choose a small task whose answer you can verify: summarize two non-sensitive notes, flag contradictions and list unresolved questions. Avoid connecting production accounts for an initial experiment. Use the task template to define the limits.

How do I know a task is finished?

Compare the deliverable with the acceptance checks you set before execution. Check sources, missing items and unintended side effects. A fluent answer or successful tool call is evidence of activity, not by itself evidence of completion.

What analytics does this preview use?

The default preview build does not load Google Analytics. The site includes an optional consent-based analytics implementation, but a production operator must configure it and finalize data-handling information before enabling it. Open “Privacy & analytics” in the footer to inspect this browser's choice.

This statement concerns the site implementation; it is not a claim about hosting-provider logs or the product's data handling, and it is not a complete privacy policy.
