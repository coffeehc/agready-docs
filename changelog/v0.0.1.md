# AgReady v0.0.1

发布日期：2026-10-26

AgReady 首个独立版本，使用独立的产品标识、配置目录及数据库 v1 基线，支持 PostgreSQL 和 SQLite。

本次发布提供 Linux amd64、Linux arm64、macOS amd64、macOS arm64 四个平台的 Server 安装包，包含内嵌 Web UI、许可证文件和校验清单。

安装与升级共用下载根目录 `https://download.agready.ai/agready`：

- `install.sh`：安装入口。
- `upgrade.sh`：Linux Server 自动升级入口。
- `versions.json`：已发布版本和各平台二进制摘要。
- `0.0.1/`：本版本安装包、`SHA256SUMS`、`BINARY_SHA256SUMS` 及发布元信息。

正常升级保留配置、密钥和业务数据目录，校验下载内容后切换版本链接并重启；启动检查失败时恢复原版本链接。xAgent 数据迁移使用独立迁移工具，不由安装或升级脚本执行。当前独立工具仅实现 PostgreSQL 到 PostgreSQL，SQLite 迁移尚不支持。

首次安装：

```bash
curl -fsSL https://download.agready.ai/agready/install.sh -o install-agready.sh
bash install-agready.sh
```

AgentPlugin 和 Runtime Assets 使用各自的发布目录与版本；Server 的版本号不代表这些组件同步发布。

主程序安装入口为 `agready/install.sh`，只安装 AgReady Server；插件通过 `agready/agentplugins/install.sh --plugins <名称>` 独立安装。Server 升级不会安装或重启插件。插件索引为空时表示尚未独立发布插件。
